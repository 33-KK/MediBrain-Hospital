# 橙白医学问答界面

2026-10-14，按用户提供的参考截图完成现有 Vue 前端改版，使用 MediBrain 品牌与已有业务接口。

## 页面与交互

- 浅杏色顶部品牌栏、白色侧栏、浅橙选中态；保留智能问答、知识图谱、医学资料库、疾病详情、问答历史、个人中心六个入口。
- 问答页采用居中限宽内容、推荐问题卡、右侧橙色提问、浅灰回答区与固定底部输入区。
- 推荐问题可换组或直接发送；新会话重置页面对话，已经保存的个人历史继续保留。
- 输入支持 Enter 发送、Shift+Enter 换行，并跳过输入法组合阶段的 Enter。长度限制为 2000 字，发送按钮与字数放在独立行，避免滚动长文本时覆盖内容。
- 保留图谱依据展开、医学资料与官方原文链接、疾病跳转和语音朗读，新增复制回答操作。语音异步请求通过序号隔离，切换会话或离开页面时停止播放并释放音频 URL。
- 登录、注册统一为一个表单，仅用户名和密码；保留现有认证接口，补充空表单校验和重复提交保护。
- 手机侧栏改为可横向滚动导航，输入框留在底部。

## 验证

前端 `vue-tsc` 和 Vite 构建、Docker 镜像构建通过。使用构建产物与真实部署 API 的本机预览完成：

1. 空登录校验、切换注册页清除校验提示、临时账号按 Enter 登录。
2. 推荐问题换组并发送、图谱问答与依据展开、医学资料问答与来源卡片。
3. Shift+Enter 只换行、Enter 发送；两次新会话后，个人历史仍显示两条测试问答。
4. 390×844 手机布局无页面横向溢出，输入区位于视口内；输入 2000 字后，输入区域底边与操作区顶边均为 764px，没有重叠。

临时账号及其测试问答已清理，独立预览进程已停止，浏览器尺寸已恢复。构建产物还在部署后浏览器中核对了品牌、导航、推荐卡片和输入区。
