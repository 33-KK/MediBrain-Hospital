# MediBrain 外网网站上线准备

更新日期：2026-10-11。目标已确认：通过外网网址提供完整系统。服务器、域名和连接方式尚待确认，当前未发布到公网。

当前优先任务调整为免费提供老师远程演示入口，详见 [老师演示说明](teacher-demo.md)。云服务器资源尚未购买，正式网站部署保留为后续方案。

## 现有基础

- Vue 前端、NestJS 后端、统一登录、只读知识图谱、医学资料库、问答及语音功能均已有实现。
- 本机站点为 `http://localhost:8090`，运行在 Docker Desktop 的 kind 集群中；该地址只表示本机访问。
- 前后端已有生产镜像构建文件和 Kubernetes 清单，可以继续复用项目，无需另建静态展示网站。

## 确认资源后选择部署方式

- 已有 Kubernetes 集群：完善现有云端清单、域名与 TLS 配置后部署。
- 已有单台 Linux 云服务器：准备完整的单机容器部署，统一提供网页与 API，数据库和模型保持在私有网络中。
- 尚无服务器：先确认预算、访问人数、服务器区域及 Ollama 模型运行位置，再选择资源。当前不购买资源或创建付费服务。

需要提供服务器服务商、操作系统、CPU/内存、是否有 GPU、域名及可使用的 SSH 主机别名。密码、私钥和 API Key 不应发在聊天中；连接信息通过本机 SSH 配置或服务商的授权方式提供。

## 上线前的具体工作

1. 建立独立部署配置和真实密钥，保留本机现有系统与数据。
2. 配置域名解析、HTTPS、网页和 API 的反向代理。现有 Ingress 尚无域名和 TLS 配置，不能直接当作已完成的正式网站入口。
3. 配置公网入口的可信代理网段；仅网页入口对外提供访问，数据库和 Ollama/Milvus 不直接暴露公网。
4. 迁移原有图谱与新资料库，保留属性类型、同名冲突记录、PDF 页码关系和待审核状态；创建资料全文索引。
5. 确定用户/历史记录是否迁移；所有账号统一登录，不再初始化管理员或授予角色。
6. 检查知识图谱、资料检索、原文阅读、问答、语音、权限、健康状态与备份恢复，再验证外部网络访问。

## 数据迁移注意

旧的 `scripts/graph-migration/export.js` 会将属性转换为字符串，并按 `名称` 匹配关系端点；资料节点没有该字段，因此不能完整迁移资料库的 PDF 页码关系。同名疾病也不能仅凭名称重建关系。

旧的 `import4.js` 会先清空目标库。这两个脚本保留作历史用途，本次公网迁移不能直接沿用。正式迁移需使用保留类型与关系标识的备份/恢复方式，在新目标库验证后再切换访问入口。

## 当前状态

已完成部署路径检查，并在源码中补齐以下设置，等待目标环境构建部署：

- 登录每个来源 IP 每分钟最多 20 次，注册每小时最多 10 次；超出返回 429，Redis 不可用时认证返回 503。
- 生产环境默认仅同源访问；需要跨域时通过 `CORS_ORIGINS` 指定完整来源，不接受通配符。
- 默认不信任转发 IP；`TRUST_PROXY_CIDRS` 只接受具体 IP/CIDR。部署时必须按真实代理网络填写，避免所有用户共用代理 IP 的配额，也避免伪造转发头绕过限制。

验证：后端 13 个测试套件、92 项测试通过，包含登录/注册配额、伪造转发 IP、代理链识别、限流存储故障及跨域配置；后端 lint 与构建均通过。

尚未选择云端目标，也未修改 DNS、开放本机端口或上传数据库。资源确认后继续生成匹配目标的配置并执行部署。本机已运行的镜像暂未替换。
