# 医疗数据合规声明

> 更新日期：2026-08-18（v1.2.0）

## 一、免责声明（医学内容）

1. **非医疗建议**：本平台提供的所有问答内容（包括但不限于疾病症状、用药、检查、饮食建议）均来自知识图谱结构化数据与通用模型生成，**仅供学习与演示参考，不构成任何医疗建议、诊断或治疗方案**。
2. **就医提醒**：如身体不适，请及时前往正规医疗机构就诊，遵循执业医师指导。平台回答末尾已对患者/普通用户身份附加就医提醒。
3. **用药警示**：涉及药品的名称、用法等信息不得作为实际用药依据，用药须遵医嘱或药品说明书。
4. **不承担医疗责任**：作者与平台对因使用本平台信息而造成的任何直接或间接损失不承担法律责任。

## 二、数据来源与版权

| 数据 | 来源 | 说明 |
|------|------|------|
| 基础图谱数据（4.9 万实体/30 万关系） | 公开医疗知识整理（演示数据集） | 仅供研究演示，禁止商用传播 |
| 扩充病种数据（scripts/graph-expansion/data/） | 基于公开医学常识整理 | 已标注字段：症状/检查/药品/宜忌食物/并发症/治疗等 |
| 药品用法说明 | 通用医学知识整理 | 非说明书原文，用药以官方说明书为准 |
| 生成回答 | 大模型（DeepSeek/百炼/Ollama） | 基于图谱事实生成，可能包含不确定信息 |

**数据使用约束**：
- 不得将图谱数据用于训练、转售或任何商业用途；
- 数据可能存在滞后、错误或遗漏，使用时须人工校验；
- 涉及个人隐私的内容不得录入图谱。

## 三、数据与隐私

1. **数据范围**：系统仅存储用户账号（用户名/密码哈希）与问答历史记录，不采集姓名、身份证、病历等个人敏感信息。
2. **密码安全**：密码使用 bcrypt 哈希存储，JWT 密钥生产环境已更换为随机值。
3. **问答历史**：用户可随时删除自己的历史记录（`DELETE /api/history`）。
4. **日志脱敏**：生产环境建议关闭或脱敏提问原文日志。
